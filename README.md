# 材料棚卸し

サロンの材料を店舗ごとに数えて、材料費率を出すページ。
スマホ1枚で終わり、**使う人にアカウントは要りません**。

数字はこのリポジトリに入っていません。品目も単価も在庫も、全部スプレッドシート側です。

## 使う人がやること

管理者から届いたリンクを開く → **名前を入れる** → 数える。以上です。

## 管理者が最初の1回だけやること

スプレッドシートを「保存先」にします。3ステップです。

### 1. スプレッドシートを作る

Googleスプレッドシートを新規作成します。中身は空のままで大丈夫です。

### 2. スクリプトを貼る

**拡張機能 → Apps Script** を開き、出ている中身を消して、
`apps-script.gs` を全部貼り付けて保存します。

**書き換えるところはありません。** シートは最初のアクセスで自動的に作られます。

### 3. 公開する

**デプロイ → 新しいデプロイ → 歯車から「ウェブアプリ」を選ぶ**

| 項目 | 値 |
|---|---|
| 次のユーザーとして実行 | 自分 |
| アクセスできるユーザー | **全員** |

「アクセスを承認」を求められたら進めます。最後に出る `.../exec` で終わるURLをコピーします。

**「全員」にしないと、開いた人がGoogleログインを求められます。** ここだけ注意です。

---

あとはページを開いて、そのURLと自分の名前を入れるだけ。合言葉は空で構いません。

つながったら、品目タブの下の **「みんなに配るリンクをコピー」** を押します。
出てきたリンクをLINEで送れば、相手は開いて名前を入れるだけで使えます。

## 合言葉をつけたいとき（任意）

`apps-script.gs` の先頭 `var KEY = '';` に文字を入れると、
その合言葉を知っている人だけが読み書きできます。
配るリンクには合言葉が入っているので、相手の手間は増えません。

## 既存の在庫表から移すとき

スプレッドシートの `品目` `棚卸` `店舗` シートに、
**ファイル → インポート → 現在のシートを置換** でCSVを読み込みます。見出し行はそのままです。

## 作り直したいとき

Apps Script の関数一覧から `setup` を実行すると、シートが空の状態に戻ります。
**入っている数字は消えます。**

## できること

| タブ | 中身 |
|---|---|
| 入力 | 品目ごとに「仕入れ」「月末在庫」。前月在庫は自動。数え終わったらLINEに貼れる報告文をコピー |
| 集計 | 売上を入れると材料費率。カテゴリ別、仕入れ未入力の品目、単価未設定の品目、CSV書き出し |
| 推移 | 過去6か月の材料費・仕入れ・材料費率。誰が入れたかも残る |
| 品目 | 店舗の追加、品目・単価・別名の編集 |

## 仕組みのメモ

- 消費税 10%。**単価は税込**で持ちます（請求書と在庫表に合わせるため）
- 使用数 ＝ 前月在庫 ＋ 仕入れ − 月末在庫。月末在庫が未入力の品目は集計に入れません
- 材料費率 ＝ 材料費(税込) ÷ 売上(税込)
- 単価が未設定の品目は金額に入れず、集計タブに一覧で出します（黙って0円にしません）
- **書き込みは `Content-Type: text/plain` で送ります。**
  `application/json` にすると preflight(OPTIONS) が飛び、Apps Script はそれに答えないので全部失敗します
- 設定（URL・合言葉・名前）は端末の localStorage にだけ残ります
