# 材料棚卸し

サロンの材料を店舗ごとに数えて、材料費率を出すページ。
スマホ1枚で完結し、**開く人にアカウントは要りません**。

- ページ … このリポジトリの `index.html`（GitHub Pages が配信）
- 保存先 … Googleスプレッドシート（`apps-script.gs` 経由）
- ライブラリなし。1ファイルで動きます

数字はこのリポジトリには入っていません。品目も単価も在庫も、全部スプレッドシート側です。

## できること

| タブ | 中身 |
|---|---|
| 入力 | 品目ごとに「仕入れ」「月末在庫」。前月在庫は自動。数え終わったらLINEに貼れる報告文をコピー |
| 集計 | 売上を入れると材料費率。カテゴリ別、仕入れ未入力の品目、単価未設定の品目、CSV書き出し |
| 推移 | 過去6か月の材料費・仕入れ・材料費率。誰が入れたかも残る |
| 品目 | 店舗の追加、品目・単価・別名の編集 |

## 置き方

### 1. スプレッドシートを用意する

1. Googleスプレッドシートを新規作成する
2. **拡張機能 → Apps Script** を開く
3. `apps-script.gs` の中身を全部貼る
4. 先頭の `var KEY = '';` を、自分で決めた合言葉に書き換える（空のままだと誰でも書けます）
5. 関数の一覧から **`setup`** を選んで一度だけ実行する → シートが4枚できます

### 2. ウェブアプリとして公開する

**デプロイ → 新しいデプロイ → 種類＝ウェブアプリ**

| 項目 | 値 |
|---|---|
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

最後に出る `.../exec` で終わるURLを控えます。
**ここを「全員」にしないと、開いた人にGoogleログインを求められます。**

### 3. ページを開いて、1回だけ設定する

GitHub Pages のURLを開くと「最初の設定」が出ます。

- Apps Script のURL … 2で控えたもの
- 合言葉 … 1で決めたもの
- あなたの名前 … 棚卸しを入れた人として残ります

### 4. みんなに配る

品目タブの下にある **「みんなに配るリンクをコピー」** を押すと、
設定が入ったリンクが取れます。それをLINEで送れば、相手は開くだけで使えます。

**合言葉が入ったリンクなので、関係ない人に送らないでください。**

## 既存の在庫表から移すとき

スプレッドシートの `品目` `棚卸` `店舗` の各シートに、
**ファイル → インポート → 現在のシートを置換** でCSVを読み込みます。
見出し行はそのまま使えます。

## 仕組みのメモ

- 消費税 10%。**単価は税込**で持ちます（請求書と在庫表に合わせるため）
- 使用数 ＝ 前月在庫 ＋ 仕入れ − 月末在庫。月末在庫が未入力の品目は集計に入れません
- 材料費率 ＝ 材料費(税込) ÷ 売上(税込)
- 単価が未設定の品目は金額に入れず、集計タブに一覧で出します（黙って0円にしません）
- **書き込みは `Content-Type: text/plain` で送ります。**
  `application/json` にすると preflight(OPTIONS) が飛び、Apps Script はそれに答えないので全部失敗します
- 設定（URL・合言葉・名前）は端末の localStorage にだけ残ります
